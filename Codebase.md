# Codebase

## Layout

- `index.html` — app shell and font loading.
- `src/main.js` — page markup and heart animation seeding.
- `src/style.css` — Tailwind import, theme tokens, keyframes.
- `src/config.js` — recipient, sender, and placeholder copy.
- `public/favicon.svg` — static asset.
- `vite.config.js` — Vite + Tailwind plugin.
- `vercel.json` — build and output settings for Vercel.

## Scripts

- `npm run dev` — local Vite server.
- `npm run build` — production build to `dist`.
- `npm run preview` — serve the production build locally.
