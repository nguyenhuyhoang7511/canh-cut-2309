# canh-cut-2309

Frontend-only birthday website. Built with HTML, CSS, JavaScript, Tailwind CSS, and CSS animations. Deploy target: Vercel.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Personalize later

Edit `src/config.js` for names and copy. Page structure lives in `src/main.js`. Styles and animations live in `src/style.css`.
